# 🎬 HELLO MOTION — Portfolio Website

একটি আধুনিক, প্রিমিয়াম এবং ডার্ক-নিয়ন স্টাইলের ভিডিও এডিটর ও মোশন ডিজাইনার পোর্টফোলিও ওয়েবসাইট। এটি সম্পূর্ণ **React.js, JavaScript, HTML, এবং CSS** দিয়ে সহজ এবং বোধগম্য কোডে তৈরি করা হয়েছে যাতে যে কোনো কোচিং বা ক্লাসে সহজে প্রেজেন্ট করা যায়।

---

## 🚀 প্রোজেক্টটি কীভাবে রান করবেন (How to Run)

১. টার্মিনাল ওপেন করুন এবং প্রজেক্ট ফোল্ডারে যান:
```bash
cd "C:\Users\Dell\.gemini\antigravity-ide\scratch\hello-motion"
```

২. ডিপেন্ডেন্সি ইনস্টল করা না থাকলে ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৪. আপনার ব্রাউজারে নিচের লিঙ্কে ভিজিট করুন:
👉 **http://localhost:5173/**

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **হুবহু রেফারেন্স ডিজাইন**: ছবিতে থাকা ডার্ক ব্যাকগ্রাউন্ড, বেগুনি গ্লো, আর্চ ফ্রেমের পোর্টফোলিও ইমেজ ও নিয়ন ইলুমিনেশন।
2. **সহজ ও ক্লিন কোড**: কোনো জটিল বা অ্যাডভান্সড লাইব্রেরি ব্যবহার করা হয়নি। সাধারণ React Hooks (`useState`) এবং পিওর CSS দিয়ে সব অ্যানিমেশন তৈরি করা হয়েছে।
3. **ইন্টারেক্টিভ মোডাল**: "Let's Talk" বা "Watch Showreel" বাটনে ক্লিক করলে চমৎকার পপ-আপ উইন্ডো ওপেন হয়।
4. **১০০% রেসপনসিভ**: মোবাইল, ট্যাবলেট ও ডেস্কটপ সব ডিভাইসে পারফেক্ট কাজ করে।
